    내 메일로 다시 받기

    저장된 브리핑을 GitHub 알림 메일로 다시 보냅니다. AI를 쓰지 않아서 몇 번이든 보낼 수 있고, 1~2분 안에 도착합니다.

    GitHub에서 직접 실행

    버튼 한 번으로 보내려면 (처음 한 번만 설정)
    1. GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
    2. Repository access: Only select repositories → 이 저장소만 선택
    3. Permissions → Actions: Read and write (다른 권한은 필요 없음) 후 생성
    4. 만든 토큰(github_pat_…)을 아래에 붙여 넣고 저장

    토큰은 이 브라우저에만 저장되며 어디에도 전송되지 않습니다(GitHub로 실행 요청을 보낼 때만 사용). 공용 컴퓨터에서는 저장하지 마세요.
