# 📰 Daily News Digest (운영 안내서)

국내·미국·영국 등 약 100개 매체의 RSS를 모아 **매일 아침 7:30(한국시간)** 에 한국어로 정리해서 **이 저장소의 이슈(Issue)로 올립니다.**
GitHub가 이슈 담당자(저장소 주인)에게 **알림 메일**을 보내므로, 메일함에서 `[뉴스 브리핑]`으로 시작하는 메일을 열면 됩니다.
내 컴퓨터도, Claude 구독도 필요 없습니다. **비용은 0원**입니다.

## 1. 받게 되는 내용
- 맨 위: **🌤 오늘의 날씨**(서울·대구·LA: 기온, 어제와 비교, 비/눈 예보, 내일 날씨) → **☀️ 오늘의 한마디**(한글/영어 응원 문장) → **📌 카테고리별 오늘의 핵심** (분야별 2~3문장)
  - 날씨는 Open-Meteo(무료·키 불필요). 가져오지 못하면 날씨 칸만 빠지고 뉴스는 정상 발송됩니다. LA는 한국 아침 기준 현지가 전날 오후라 "(현지 N일)"로 표시됩니다.
  - 도시 바꾸기: `news_digest.py`의 `WEATHER_CITIES`(이름, 위도, 경도). 응원 문장은 `daily_messages.py`에서 나옵니다. 직접 쓴 문장 조각을 조합한 **61,499가지**라 하루 하나씩 약 168년간 겹치지 않고, 인용이 아니라서 출처 오류가 없습니다. 새 조각은 해당 목록 끝에 `한글|English` 한 줄만 추가하면 됩니다.
- 카테고리 순서: 세계 이슈 → 경제·증시 → 코인 → 문화예술 → **AI** → 정치·사회 → IT·과학 → 스포츠
- **AI 카테고리**: 새 모델 출시·벤치마크/리더보드 변화·가격/API/기능 변경·교육/업무 활용·AI 기업 동향·규제. OpenAI, Google DeepMind·Google AI, Anthropic, Hugging Face, Mistral 같은 **공식 발표**와 MIT Technology Review·TechCrunch·The Verge·Ars Technica·Wired·Guardian의 AI 섹션, Simon Willison·Latent Space·Import AI·Interconnects·One Useful Thing 같은 전문 블로그, 교육 쪽 EdSurge, 국내 AI타임스를 모읍니다. 모델 이름·버전·점수·가격은 기사 원문에 있는 것만 쓰고, 원문에 없는 소수·퍼센트 수치가 나오면 원문 제목으로 대체합니다.
- 우선순위: ① 세계 정세(전쟁·국가 관계) ② 경제(주식·코인) ③ 문화예술(국내 소식 최소 3건 + 해외 미술계) ④ AI(생성형 AI 동향·새 모델·벤치마크)
- 맨 아래: 참고한 신문사 목록, 그리고 한 줄 **실행 정보**(기사 몇 건, 어떤 AI 모델, 읽지 못한 매체)
- 전날 보낸 기사와 겹치는 것은 자동으로 제외됩니다.

## 2. 현재 설정 상태
| 항목 | 상태 |
|---|---|
| 실행 | GitHub Actions, 매일 한국 06:10·07:30·08:30에 발송 예약 + 10:30·13:30·16:30에 재시도 예약(누락 대비). GitHub 예약이 몇 시간 늦거나 일부 빠지는 일이 잦아 실제 도착은 오전 7~10시경이며, 하루 한 통만 발송됨 |
| 요약 엔진 | OpenRouter 무료 모델 (`OPENROUTER_API_KEY` 비밀값 등록됨) |
| 받는 방법 | GitHub 이슈 알림 메일 (받는 주소는 GitHub 계정 설정의 *Default notifications email*) |
| 비용 | 0원 (Actions 월 2,000분 무료 중 하루 3~8분 사용) |

## 3. 문제가 생겼을 때 — 이슈 제목으로 원인 확인
요약이 실패하면 메일이 끊기는 대신 **헤드라인만** 보내며, 이슈 맨 위 한 줄에 이유가 적힙니다.

| 이슈 맨 위 문구 | 뜻 | 할 일 |
|---|---|---|
| 무료 사용 한도를 초과해 오늘은 헤드라인만… | 무료 모델이 그날 한도/혼잡 | 아무것도 안 해도 됨. 다음 날 자동 복구 |
| 지정된 무료 AI 모델이 … 사라졌거나 이름이 바뀌어… | 무료 모델 목록이 바뀜 | 아래 4-② 참고 |
| AI 요약에 실패해 헤드라인만 제공합니다 | 키 만료/오류 등 | Actions 로그 확인(아래 5) 후 키 재발급 |
| (메일 자체가 안 옴) | 실행 실패 또는 알림 설정 | 5번 확인, 그다음 6번 |

## 4. 자주 바꾸는 것
**① 매체/카테고리 바꾸기** — 저장소의 `feeds.json`을 웹에서 편집(연필 아이콘 → Commit). 한 줄이 매체 하나입니다.
`outlet`(이름), `region`(국내/미국/영국/기타 해외), `category`(세계 이슈·경제·증시·코인·문화예술·정치·사회·IT·과학·스포츠), `url`(RSS 주소), 필요하면 `max_items`(최대 기사 수), `max_age_hours`(며칠 전 기사까지).
읽지 못한 매체는 메일 맨 아래 "읽지 못한 매체"에 표시되니, 계속 뜨는 매체는 줄을 지우면 됩니다.

**② AI 모델 바꾸기** — 저장소 **Settings → Secrets and variables → Actions → Variables** 에서 `OPENROUTER_MODELS`
(쉼표로 구분, 예: `nvidia/nemotron-3-ultra-550b-a55b:free,google/gemma-4-31b-it:free`)를 새로 만들거나 지우면 됩니다. 비워 두면 기본값(Nemotron 3 Ultra → Gemma 4 31B → Nemotron → Gemma 4 26B)을 씁니다.
무료 모델 목록은 https://openrouter.ai/models?q=free 에서 볼 수 있습니다. 단, **추론 모델(reasoning 필수)** 은 빈 응답을 내는 일이 있어 피하세요.

**③ API 키 다시 만들기** — https://openrouter.ai/settings/keys 에서 새 키를 만들고, 저장소 **Settings → Secrets and variables → Actions → Secrets** 의 `OPENROUTER_API_KEY`를 새 값으로 바꿉니다. 키는 채팅·이슈·글에 붙여넣지 마세요.

**④ 지금 바로 한 번 실행** — **Actions 탭 → Daily News Digest → Run workflow**. (`dry_run`에 체크하면 이슈를 만들지 않고 실행 로그에만 결과를 보여줍니다.)
무료 모델은 하루 50회 한도(UTC 기준 날짜)라, 시험 실행을 하루에 여러 번 하면 그날 아침 자동 발송이 헤드라인으로 떨어질 수 있습니다. 하루 1~2회만 쓰세요.

## 5. 실행 기록(로그) 보는 법
저장소 **Actions 탭 → 가장 위 실행 클릭 → send → "Run" 단계**.
- `AI 요약 완료: openrouter` / `OpenRouter 모델 사용: …` : 정상
- `[warn] OpenRouter 실패 (모델명…)` : 그 모델이 실패한 이유(한도·시간 초과·형식 오류)
- `AI 요약 정리: … 제거 {…}` : 검증에서 걸러낸 항목 수(없는 링크·중복·깨진 문자·근거 없는 숫자·근거 없는 점수)
- `핵심 요약 재작성: N/M개 카테고리 반영` : 2차 작업 결과

## 6. 꼭 알아둘 점
- **저장소는 현재 공개(Public)입니다.** 이슈로 올라가는 브리핑과 웹사이트가 누구에게나 보입니다. 공개 저장소는 60일간 저장소 활동이 없으면 GitHub가 예약 실행을 정지시키는데, 매일 보관 파일(`archive/`)이 커밋되고 워크플로 "켜기" 호출을 함께 하므로 대부분 막히지만 **보장은 아닙니다.** 정지되면 Actions 탭에서 "Enable workflow"를 누르세요. 비공개로 돌리면 Pages 웹사이트는 유료 플랜이 아닌 이상 쓸 수 없습니다.
- 받는 메일 주소를 바꾸려면 GitHub **Settings → Emails** 에서 새 주소를 추가·인증하고 *Default notifications email* 로 지정합니다. 알림이 안 오면 **Settings → Notifications** 의 Participating/Watching 설정도 확인하세요.
- **웹사이트(GitHub Pages)**: `https://nikkikim.github.io/claude1/`. 왼쪽 **달력**에서 점이 찍힌 날짜를 누르면 그날 브리핑이 열리고(이전/다음 브리핑 버튼, 이 달의 목록, 모바일은 📅 버튼), 맨 위에 날씨·한마디·카테고리별 핵심, 카테고리 바로가기가 있습니다. 어두운 화면 전환(🌓) 지원. 검색엔진에는 노출되지 않게(noindex) 했지만 **링크를 아는 사람은 누구나** 볼 수 있습니다. 처음 한 번만 *Settings → Pages → Source* 를 **GitHub Actions** 로 바꿔 두어야 합니다(완료됨). 뉴스를 새로 만들지 않고 사이트만 다시 올리려면 Actions → Run workflow 에서 `site_only` 체크.
  - 용량: 하루 약 15~30KB(JSON). 1년 약 10MB라서 Pages 한도(사이트 1GB)까지 수십 년 분량이 들어가고 저장소 용량도 문제없습니다. 화면 파일은 `site/`, 보관 파일은 `archive/날짜.json`, 생성 코드는 `build_site.py`.
- **✉ 이메일 보내기 버튼(웹사이트 오른쪽 위)**: ① *지금 보내기* — 보고 있는 날짜의 브리핑을 GitHub 알림 메일로 **AI 없이** 다시 보냅니다(몇 번이든 가능, 제목은 `[뉴스 브리핑·재발송]`). 처음 한 번 GitHub 토큰(Fine-grained, 이 저장소만, *Actions: Read and write*)을 이 브라우저에 저장해야 버튼 한 번으로 작동합니다. 토큰이 없으면 *GitHub에서 직접 실행*(Actions 화면)으로도 같은 일을 할 수 있습니다(`resend` 체크, 날짜는 `resend_date`). ② *메일 앱으로 보내기* — 내 메일 앱에 핵심 요약과 링크를 채워 다른 사람에게 공유.
- **자동 발송 안전장치**: 매일 06:10·07:30·08:30(KST) 정규 실행(이미 오늘 발송됐으면 건너뜀) + 10:30·13:30·16:30(KST) **AI 재시도 실행**. AI가 실패해 헤드라인만 나간 날은 직전 발송·시도 후 **약 3시간이 지난 뒤** 재시도하며(무료 한도·혼잡이 풀릴 시간을 줌, 최대 3번), 성공하면 완성본을 다시 발송하고 실패하면 조용히 넘어갑니다. 예비 실행은 ① 정규 실행이 GitHub 사정으로 누락·실패했으면 대신 발송하고, ② 아침 브리핑이 **AI 요약 없이(무료 한도 초과 등) 헤드라인만** 나갔다면 한도가 채워진 뒤인 이 시각에 AI 요약을 **한 번 더 시도해 완성본을 다시 발송**하며(재시도도 실패하면 추가 발송 없음), ③ 이미 AI 요약본이 나갔다면 아무것도 하지 않습니다. 무료 AI 한도는 UTC 기준 하루 단위라 한국시간 오전 9시에 새로 채워집니다. 사이트 배포·보관 단계가 실패해도 메일 발송에는 영향이 없습니다.
- **브리핑 이슈는 자동으로 댓글이 잠깁니다**(낯선 사람의 댓글 알림 방지, 저장소 주인·협력자만 댓글 가능). 끄려면 Variables에 `ISSUE_LOCK=false`. 낯선 사람이 새 이슈를 여는 것은 Settings → Moderation options → Interaction limits(최대 6개월)로 제한합니다.
- **6개월마다 하는 설정 알림**: Interaction limits(낯선 사람의 이슈·댓글 제한)는 최대 6개월이라, 만료 14일 전부터 브리핑 맨 위(이슈·웹사이트·텔레그램·메일)에 **다시 거는 방법**이 나옵니다. 건 날짜는 Variables의 `INTERACTION_LIMIT_SET_ON`(YYYY-MM-DD, 비우면 2026-11-05로 계산). 다시 걸고 이 날짜를 오늘로 고치면 알림이 사라지고 6개월 뒤 다시 나옵니다. `off`로 두면 알림을 끕니다.
- 시험 삼아 올라온 예전 이슈(#1~#7 등)는 Close(또는 삭제)해도 됩니다. 단, **가장 최근의 `[뉴스 브리핑]` 이슈는 지우지 마세요** — 다음 날 중복 기사를 제외하는 기준으로 쓰입니다(지워도 오류는 없고 겹치는 기사가 한 번 보일 뿐).

## 7. 한계 (무료 AI의 어쩔 수 없는 부분)
- 무료 모델은 가끔 틀립니다. 코드가 **없는 링크·중복·한자 섞임·근거 없는 숫자**는 걸러내지만, 기사 내용을 약간 잘못 요약하는 것까지는 막지 못합니다. 중요한 건 링크를 눌러 원문을 확인하세요.
- 해외 매체 제목은 번역 요약본에서만 한국어이고, 헤드라인만 나가는 날에는 영어 원문 제목 그대로입니다.
- 일부 사이트는 RSS 주소가 바뀌거나 GitHub 서버 접속을 막아 일시적으로 빠질 수 있습니다(메일 하단에 표시).

## 8. 다른 방법으로 받고 싶을 때 (선택)
이메일(SMTP)·텔레그램도 지원합니다. 저장소 Secrets에 아래 값을 넣으면 해당 채널이 켜집니다(하나라도 있으면 GitHub 이슈 알림은 꺼지고, 함께 쓰려면 Variables에 `ISSUE_NOTIFY=true`).
- 이메일: `SMTP_USER`, `SMTP_PASSWORD`(Gmail은 앱 비밀번호), `MAIL_TO`(쉼표로 여러 명), 선택 `SMTP_HOST`/`SMTP_PORT`
- 텔레그램: `TELEGRAM_BOT_TOKEN`(@BotFather), `TELEGRAM_CHAT_ID`
- 다른 AI: `GEMINI_API_KEY`(무료 티어가 계정/프로젝트에 따라 막혀 있을 수 있음), `ANTHROPIC_API_KEY`(유료, Claude 구독과 별개). 여러 개를 넣으면 claude → gemini → openrouter 순으로 시도합니다.

## 9. 로컬에서 시험 (개발자용)
```bash
pip install -r requirements.txt
python news_digest.py --dry-run --no-llm   # 키 없이 헤드라인 모드로 digest.html 생성

```
